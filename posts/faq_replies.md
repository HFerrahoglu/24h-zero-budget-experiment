**S1: "Did an AI write this post? / Isn't this AI spam?"**
```
Yes, the agent drafted it and I'm the human posting it. That's the experiment, and it's said at the top. I checked this sub's rules before posting (no AI rule here). The research behind it is real, though. Every rule in the tool links to its source so you can check it yourself.
```

**S2: "Why charge for this? Lists of launch sites are free."**
```
Fair point. Lists are free, and the free version here covers the 12 biggest channels at no cost. What we didn't find elsewhere is the rule check itself: AI-text bans, account-age gates, real queue times, posting days, each with its source and date. The $7 kit is also our test of whether anyone values that enough to pay. Telling us "no" is useful data too.
```

**S3: "X is wrong / outdated."**
```
Thanks, that's exactly what I need. Do you have a link to the current rule? I'll pass it to the agent and update the row today. Each row shows whether it came from the platform's own page or from a third-party tracker, and the third-party ones are the most likely to be stale.
```

**S4: "How is this different from LaunchFill / other autofill extensions?"**
```
Those mostly autofill forms for a list of directories, and they do that well. This one starts a step earlier: it tells you which channels will remove your post or make you wait months, given your account age and whether AI helped write it. The kit has a bookmarklet too, but that's a convenience, not the main point.
```

**S5: "Directories are useless, only PH/HN matter."**
```
For traffic, that's mostly true, and the data agrees: many free directory queues are 50 days to over a year. That's partly why the tool exists. It shows you what's actually reachable from where you stand, and with a new account PH and HN often aren't.
```

**S6: "Does the bookmarklet send my data anywhere?"**
```
No. The profile is stored inside the bookmark and in your browser's localStorage. The script only fills visible empty fields on the page you're on and never presses submit. The full kit is a single offline HTML file with no network requests. The free page only sends anonymous counters (page load / filter click / buy click, tagged with the ?ref of the link).
```

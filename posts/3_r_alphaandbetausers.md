Link (free, no sign-up, no email): https://hferrahoglu.github.io/where-can-i-post/?ref=rab

What I'm looking for from testers:
- Try it with your real situation. Does any verdict look wrong?
- Which channel did you expect to see but didn't?
- How does it work on mobile?

Known limits: the data is a 2026-11-05 snapshot, and some rows rely on third-party rule trackers (they're labeled). There's an optional $7 full kit (50 channels, an autofill bookmarklet and a tracker), but you only need the free page to test.

Disclosure: built by an AI agent (Claude) as part of a public 24h experiment. I'm the human operator and this text was drafted by the agent. Log: https://github.com/HFerrahoglu/24h-zero-budget-experiment
